# 2026-06-19 客服回饋：知識庫待補項目整理

本文件整理自 `ai_feedback_2026-06-19.csv` 中客服實際回饋，聚焦「需要補充知識庫」的問題。第 6 點個資遮罩暫不處理。

## 優先級 A：高頻或高風險知識缺口

### 1. 帳單/合約查詢需地址核對

客服回饋：
- 用戶可能有多筆資料，應再進一步詢問住址，交叉核對後再提供正確費用、金額、期間，以免用戶誤判。
- 查詢合約，應再請客提供裝機住址。
- 使用者追問「你說的是哪個住址？」時，應請客戶提供住址核對。

需補知識：
- 使用姓名與電話查帳單或合約時，若可能有多筆資料，需補問「裝機地址」。
- 查到金額、帳期、合約資訊前，應先確認地址，避免同名或多戶誤判。

建議回答方向：
- 「為避免同名或多筆資料誤判，請再提供裝機地址，確認後我再協助查詢帳單/合約資訊。」

### 2. 授權到期/未授權畫面

客服回饋：
- 如已繳費，畫面授權到期，可能是切到成人頻道，應請客直接選台，不是只叫設備關機重開。
- 機上盒一直出現授權到期，應與用戶確認目前切換在第幾頻道，是否為需另付費的加值節目，或確認繳費期限。

需補知識：
- 授權到期可能原因：成人頻道、加值頻道未訂購、欠費、授權異常。
- 先詢問目前第幾台。
- 請客戶先切到一般基本頻道確認。
- 若基本頻道也授權到期，再確認繳費/授權狀態。

建議回答方向：
- 「請先確認目前停在哪一台。若是成人頻道或加值頻道，可能需要另外訂購；請先切到一般基本頻道，例如台視/中視/民視，再確認是否能正常收看。」

### 3. 裝網路/新申裝費用與方案

客服回饋：
- 「我要裝網路 請問費用」不應回答資料不足。
- 不管要裝什麼方案，應有基本頻寬說明。
- 「我想安裝網路」應提供優惠方案，不應進入故障排錯。

需補知識：
- 基本頻寬方案：100M、300M、500M 等。
- 月租、半年繳、年繳。
- 裝機費、押金、綁約期。
- 新申裝適用條件。
- 大里區、太平區、烏日區、霧峰區等服務區域適用說明。

建議回答方向：
- 「目前常見寬頻方案包含 100M、300M、500M，實際月租、裝機費、押金與優惠需依地址與申辦資格確認。若您要新申裝，可先提供服務地址，由客服確認可施工與適用方案。」

### 4. 電視＋網路同裝優惠

客服回饋：
- 詢問電視跟網路一起裝，有什麼優惠方案時，應提供好視成雙 NO7 或好視成雙 NO8。

需補知識：
- 好視成雙 NO7。
- 好視成雙 NO8。
- 300M/300M、500M/500M 費用。
- 贈品、加值服務、綁約期間、違約金。
- 申辦資格與地址限制。

建議回答方向：
- 「電視＋網路同裝可參考好視成雙 NO7/NO8 類型方案，常見包含 300M/300M 或 500M/500M，實際月租、贈品與綁約條件需由客服依地址與資格確認。」

### 5. 指定專案違約金

客服回饋：
- 115 年 5 月行銷方案-母親節專案違約金：2400 元，逐月遞減。
- 如查無方案，不能提供其他方案來說明。

需補知識：
- 115 年 5 月行銷方案-母親節專案。
- 違約金 2400 元。
- 逐月遞減規則。
- 查無指定方案時，禁止拿其他方案替代回答。

建議回答方向：
- 「目前查到該專案違約金為 2400 元，採逐月遞減。若無法確認是否為同一專案，需請客服依實際合約資料確認，不能用其他方案違約金替代。」

需補知識：

- 全家 FamiPort 操作方向。
- 官網線上繳費。
- 哈TV行動客服 APP。

## 優先級 C：技術排錯知識

### 11. 網路速度慢

客服回饋：
- 網路速度很慢，建議可至 www.speedtest.net 先做測速。
- 「是很慢不是不能上網」應問是只有玩線上遊戲時很慢，還是都很慢。

需補知識：
- 測速網址：www.speedtest.net。
- 需區分：全部網站/APP 都慢、只有遊戲慢、只有影片慢、特定 APP 慢。
- 爆 ping、遊戲連線不順、網速慢應分開處理。
- 可要求提供下載/上傳數字。

### 12. 手機不能上網

客服回饋：
- 應請檢查手機目前連線的是 Wi-Fi 訊號還是門號的 4G 網路。

需補知識：
- 手機不能上網先確認 Wi-Fi 或 4G/5G。
- 若是 4G/5G，可能非有線寬頻問題。
- 若是 Wi-Fi，確認是否連到正確 SSID、重新連線、重開 Wi-Fi。

### 13. 電腦不能上網

客服回饋：
- 應詢問電腦是透過 Wi-Fi 連線還是接實體網路線。

需補知識：
- Wi-Fi 連線排查。
- 有線網路線排查。
- 確認網路線是否插緊、換 LAN 孔、重開數據機/分享器。

### 14. 機上盒自動關機再開機

客服回饋：
- 如果拔插機上盒電源後，機上盒仍不斷自動關機再開機，需與真人客服預約維修。

需補知識：
- 先拔插機上盒電源。
- 觀察是否仍反覆重開。
- 若仍發生，轉真人客服或預約維修。

### 15. 電視畫面 lag

客服回饋：
- 有畫面但是會 lag，不應重複詢問無訊號、黑畫面、錯誤代碼。
- 可以直接引導客戶重啟。

需補知識：
- 有畫面但 lag 的排查流程。
- 先重啟機上盒。
- 若仍 lag，再確認是否單一頻道、全部頻道、尖峰時段或需維修。

### 16. 電視畫面不清

客服回饋：
- 電視不清可詢問第幾台，或嘗試重啟。

需補知識：
- 詢問第幾台。
- 單一頻道或全部頻道。
- 重啟機上盒。
- 若部分頻道異常，可嘗試重搜/恢復預設。

### 17. 遙控器按數字沒有反應

客服回饋：
- 建議確認遙控器有無亮紅燈。
- 如有亮紅燈，可以檢查機上盒 IR 接收器有無亮燈、脫落，或重啟機上盒。
- 如沒有亮紅燈，可能故障，會請工程現場判斷。
- 如需更換會收取遙控器費用，不同型號價格不同。

需補知識：
- 遙控器亮紅燈/不亮紅燈的判斷。
- IR 接收器檢查。
- 機上盒重啟。
- 更換費用與型號差異。

### 18. 遙控器價格

客服回饋：
- 一般型遙控器 300 元，保固一年。
- 語音遙控器 400 元，保固一年。

需補知識：
- 一般型價格與保固。
- 語音型價格與保固。
- 是否需工程或客服確認型號。

### 19. 雙模機遙控器拷貝電源鍵

客服回饋：
- 雙模機遙控器若要拷貝/學習電視電源鍵，需將原廠遙控器與雙模機遙控器紅外線發射端相對，距離約 3～5 公分。
- 按雙模機遙控器上的「學習/設定」鍵 3 秒進入學習模式。
- 再按雙模機遙控器要設定的「電源鍵」。
- 最後按原廠電視遙控器的「電源鍵」。
- 指示燈閃爍 3 次後繼續保持常亮，表示學習成功。
- 學習完成後按「OK」保存。

需補知識：
- 完整操作步驟。
- 不同型號按鍵名稱與燈號可能不同。
- 失敗時需客服確認遙控器型號。

## 優先級 D：產品與裝機相關

### 20. Wi-Fi 分享器/Mesh 租借或加購

客服回饋：
- Mesh WiFi-5：半年繳 150 元/顆、年繳 300 元/顆。
- Mesh WiFi-6：半年繳 300 元/顆、年繳 600 元/顆。
- 單位應為「顆」，不是「組」。
- 可透過聯網機上盒：VIP會員 → 優惠專區 → 加值服務 → MESH WIFI 加值服務。

需補知識：
- 是否販售或僅租借/加購。
- WiFi-5/WiFi-6 費用。
- 單位：顆。
- 申辦路徑。

### 21. 新增 Wi-Fi AP/分享器設定

客服回饋：
- 請參照該品牌使用說明書連至 Wi-Fi 分享器設定畫面。
- 網路連線類型請選動態 DHCP 或浮動 IP。
- 再設定 Wi-Fi 名稱及密碼即可。

需補知識：
- 一般 AP/分享器設定方向。
- DHCP/浮動 IP。
- Wi-Fi 名稱與密碼設定。
- 橋接、固定 IP 或特殊設定需工程/客服確認。

### 22. 工程師假日是否上班

客服回饋：
- 可分裝機和維修回覆用戶。
- 裝機工程受量控安排。
- 維修工程為輪值。
- 假日有開放裝機預約，但仍需透過真人客服確認是否仍有空缺可約裝。

需補知識：
- 裝機假日預約規則。
- 維修假日輪值規則。
- 實際到府時間需客服確認。

## 建議知識庫欄位

建議每筆補充資料至少包含：

- `問題關鍵字`
- `標準回答`
- `適用條件`
- `需追問欄位`
- `不可回答/不可推論事項`
- `是否需轉真人客服`
- `資料來源`
- `最後更新日期`

2. 授權到期/未授權畫面
3. 裝網路費用與基本頻寬方案
4. 電視＋網路同裝優惠
5. 指定專案違約金
6. 帳單遺失/超商繳費/Apple Pay

8. 遙控器價格與故障排查
9. 低收入戶/身心障礙戶優惠
10. 工程假日服務與 Wi-Fi AP 設定
