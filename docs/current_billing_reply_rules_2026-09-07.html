1

查詢本期待繳帳單

適用於查帳單、帳單金額、帳單內容、帳單明細、本期帳單、查月租或查月費等問題。

查詢前必須具備
  • 客戶編號。
  • 或戶名加上帳務系統登記的聯絡電話。
系統會回覆
  • 有待繳時：帳單項目、金額、API 有提供時的日期與合計。
  • 查無未繳時：目前尚無須繳納的費用。
  • 資料不足時：要求補齊身分核對資料。
日期提醒：單筆帳單的日期會標示為「繳費到期日」。多筆帳單回傳時，系統可能顯示「已繳費迄日」；這不一定等於繳費截止日，對外不可自行解讀。

您好，目前系統可協助查詢本期待繳帳單。待下期帳單產生後，請留意相關通知，謝謝。

3

超商已繳，但帳單仍顯示

適用於客戶明確表示已在超商繳費，且目前仍查得到帳單、待繳、欠費或費用。

您好，超商繳費入帳可能需要作業時間，通常不一定會即時更新。

請先保留繳費收據或交易明細，以便後續核對。

若需確認是否已入帳，建議提供繳費收據資訊，由真人客服協助查詢。

不可做的事：不能因為客戶表示已繳費，就回覆目前無待繳、保證已入帳，或推測入帳時間。
4

已繳費後要求恢復服務

這與「帳單仍顯示」不同。客戶若已繳費並要求恢復網路、恢復電視，或表示已繳費仍無法使用服務，系統會要求超商繳費收據進行確認。

1. 上傳收據請客戶上傳超商繳費收據圖片。
2. 辨識條碼讀取第一段、第二段、第三段條碼。
3. 確認繳費以條碼向帳務系統確認繳費資料。
4. 處理復線完成後請客戶重啟數據機或機上盒確認服務。
目前已知限制：規則設定要求此情境優先切換到收據條碼流程；但對話已經停在網路排錯時，仍有一筆回歸案例被延續為排錯、未切換至收據流程。此行為尚待修正。
5

繳費後開通、補發帳單與紙本帳單

繳費後開通

  • 官方網站與哈 TV 行動客服 APP 可進行線上刷卡繳費。
  • 線上刷卡、IBON、FamiPort 繳費方式會自動開通。
  • 服務仍無法使用時，先重啟數據機或機上盒。

補發與紙本帳單

  • 補發簡訊帳單需戶名與帳務系統登記電話。
  • 簡訊帳單不可改寄或指定其他電話。
  • 紙本帳單申請或寄送設定由真人客服協助。
6

調整後的驗證清單

  • API 登入資料已帶入可用客戶識別時，可查詢本期待繳帳單。
  • 無 API 登入客戶識別時，必須同時要求戶名與登記電話，不可要求客戶自行提供客編。
  • 查無未繳後，不可改查合約到期日或預估下期金額。
  • 過往繳費、入帳紀錄與帳單期間必須引導 APP 或官網。
  • 超商已繳但帳單仍存在時，不可保證已入帳。
  • 已繳費且要求復線時，應要求收據三段條碼並走確認流程。
  • 條碼不足時，應要求補齊，不能直接執行復線。
