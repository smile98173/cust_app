# 現行系統帳務回覆規則（2026-09-07）

本文件描述目前程式實際設定的帳務處理方式，供客服、測試與後續回歸驗證使用。

## 適用範圍

系統可處理的帳務相關問題分為四類：

1. 查詢**本期待繳帳單**或目前是否有待繳。
2. 說明**過往繳費、入帳紀錄、下期帳單與帳單期間**的查閱方式。
3. 處理**已繳費但帳單仍顯示**的入帳說明。
4. 客戶提供**超商繳費收據**後，確認繳費並處理欠費復線。

系統不會把本期待繳查詢結果當成歷史繳費、下期帳單、合約資料或入帳確認。

## 1. 查詢本期待繳帳單

### 觸發情境

- 查帳單、查詢帳單、帳單金額、帳單內容、帳單明細、本期帳單。
- 查月租、查月費，但客戶沒有在問方案內容、合約或優惠。

### 身分核對條件

訪客查詢前必須提供「客戶編號、戶名、登記電話」任兩項。已登入網站且 API 已帶入受信任客編時，可直接以該客編查詢。

若資料不足，系統會先要求補齊，不會直接回覆金額。

### 查詢結果的回覆原則

| 查詢結果 | 系統回覆方式 |
| --- | --- |
| 有待繳帳單 | 顯示帳單項目、金額及 API 有提供時的日期，並計算合計。 |
| 查無未繳帳單 | 回覆「尚無須繳納的費用」，並提醒已繳費客戶可將設備關機重開後再確認。 |
| 客戶資料不存在 | 若為登入會員查詢，請重新登入後再試或轉真人客服核對；若為訪客查詢，請客戶確認所提供的客戶編號、戶名、登記電話任兩項是否與帳務資料一致。 |
| API 查詢失敗或回傳不明資料 | 不自行推論帳務狀態，改顯示系統回傳訊息或請稍後再試。 |

### 日期欄位注意事項

一般單筆帳單回傳的日期會顯示為「繳費到期日」。若 API 一次回傳多筆帳單，目前畫面可能顯示「已繳費迄日」；此欄位名稱不一定等於繳費截止日，對外回覆時不可自行解讀日期意義。

## 2. 系統不直接查詢的帳務資訊

以下問題不會呼叫本期待繳帳單查詢：

| 客戶問題 | 現行處理方式 |
| --- | --- |
| 過往繳費紀錄、已繳費明細、入帳紀錄、入帳確認 | 引導客戶至行動客服 APP 或官網查閱。 |
| 本期帳單期間、繳費起訖日、費用期間 | 說明系統僅查本期待繳，並引導至 APP 或官網。 |
| 前一輪查無待繳後追問下期帳單、下次繳費時間 | 說明待下期帳單產生後留意通知；不預估日期或金額。 |
| 帳單寄送地址 | 屬個人資料，改由真人客服核對。 |

目前固定對外說法如下：

> 若需查詢已繳費明細或入帳紀錄，可至行動客服 APP 或官網查閱。很高興為您服務，謝謝。

> 您好，目前系統可協助查詢本期待繳帳單。待下期帳單產生後，請留意相關通知，謝謝。

## 3. 已繳費但仍查到帳單

### 適用情境

客戶明確表示已在超商繳費，且目前仍查得到帳單、待繳、欠費或費用。

### 現行回覆

> 您好，超商繳費入帳可能需要作業時間，通常不一定會即時更新。
>
> 請先保留繳費收據或交易明細，以便後續核對。
>
> 若需確認是否已入帳，建議提供繳費收據資訊，由真人客服協助查詢。

這個情境只是在說明「帳單尚未更新」，不會因為客戶說已繳費就回覆目前無待繳，也不會保證已經入帳。

## 4. 已繳費後要求恢復服務

這和「帳單還在」不同。若客戶表示已繳費，並要求恢復網路、恢復電視，或已繳費但仍不能使用服務，系統的設定流程如下：

1. 請客戶上傳清楚、完整的超商繳費收據圖片。
2. 系統僅從圖片辨識收據格式與第一段、第二段、第三段條碼，並先確認其確為超商繳費收據。
3. 圖片不完整、條碼不清楚或無法確認收據來源時，請客戶重新上傳，不可執行復線。
4. 確認後才以圖片辨識出的條碼查核繳費，並處理欠費停用後的復線。
5. 完成後提醒客戶重啟數據機或機上盒，再確認服務。

不得接受客戶在聊天室手動輸入三段條碼，也不得因只看到三段條碼文字就呼叫收據復線 API。客戶沒有收據、不是超商繳費，或圖片／條碼不足時，不會假設已入帳；系統會要求重新上傳完整收據或改由真人客服核對。

### 已知測試狀態

規則設定要求「已繳費要求復線」優先進入收據條碼流程；目前有一筆回歸測試發現，當對話已經停留在網路排錯流程時，這句話可能被延續為排錯，而沒有切換到收據流程。此項應保留為待修正的回歸案例，不能當作已完全保證的行為。

## 5. 線上與超商繳費後的自動開通說明

客戶詢問線上繳費後是否會開通時，系統目前說明：

- 可透過官方網站的線上繳費專區，或哈 TV 行動客服 APP 完成線上刷卡繳費。
- 線上刷卡、IBON、FamiPort 繳費方式會自動開通。
- 若服務仍無法使用，請先重啟數據機或機上盒再確認。

這段只適用於客戶詢問繳費後開通方式，不能取代實際帳務入帳查核。

## 6. 補發簡訊帳單與紙本帳單

### 補發簡訊帳單

客戶說補寄帳單、補發帳單、簡訊帳單或沒收到帳單時，系統會收集戶名與帳務系統登記電話後申請補發。

- 簡訊帳單只能寄送至帳務系統登記電話。
- 不可改寄或指定到其他電話。

### 紙本帳單

紙本帳單的寄送或申請需要真人客服協助，AI 不直接變更寄送設定。

## 7. 測試檢查清單

每次調整帳務相關流程後，至少驗證以下情境：

1. API 登入資料已帶入可用客戶識別時，可查本期待繳帳單。
2. 沒有 API 登入客戶識別時，必須同時要求戶名與登記電話，不可要求客戶自行提供客編。
3. 查無未繳後，不可改查合約到期日或預估下期金額。
4. 過往繳費、入帳紀錄與帳單期間應導向 APP 或官網。
5. 超商已繳但帳單仍存在時，不可保證已入帳。
6. 已繳費且要求復線時，應要求上傳清楚完整的超商繳費收據圖片，再由 OCR 辨識條碼並走確認流程。
7. 圖片、收據來源或條碼不足時，應要求重新上傳完整收據；不可接受手動條碼或直接執行復線。

## 實作位置

- 帳務意圖與直接回覆：`app/services/intent_router.py`
- 帳務路由原則：`app/services/router_prompt.py`
- 區域政策文字：`app/services/regional_policy.py`
- 客戶 API、帳單解析、收據條碼與復線：`app/services/tool_manager.py`
- 身分資料與條碼欄位收集：`app/services/slot_manager.py`
